# slotkaleidoscope

Live Solana mainnet as a **brass parlor kaleidoscope**.

The tumble advances with the slot clock. Colored shards glimpsed in the facets are recent txs — hue by program family. Spin blur / lamp glare ≈ fee pressure. Cracked or soot-black shards ≈ failed txs. Cap the eyepiece to freeze a sample.

Not an explorer. Not a dashboard. Not a newspaper.
